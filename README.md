# D500 Workbench

BA7KTC / JukZeon 维护的即时通 D500 网页写频工作台。

[打开工作台](https://d500.example.com/) · [协议与验证范围](docs/SERIAL_PROTOCOL.md) · [DAT 格式](docs/DAT_FORMAT.md)

面向无航空接收的旧版 D500。信道、DAT、表格和设备配置在浏览器本地处理，不上传到服务器。

## 功能

- 000–199 信道表格编辑、右侧参数栏、搜索、筛选、批量修改、复制、移动与撤销。
- CTCSS / DCS 类型分开，预设、手动值与数字哑音正反码分别选择。
- 42 项整机菜单，A/B 与展开的 C/D 区频点、频差、收发哑音及 8 项参数，开机文字编辑。
- DAT、Excel、CSV、TSV 导入；DAT 与完整方案导出。未编辑的数据、未知位及原始名称保留。
- 浏览器草稿、完整方案备份、读机原始配置备份及通信记录。
- Web Serial 电台读取、选择范围的写入差异预览、写前读取与备份、独立写会话、写后全区回读比较。
- 中性灰白的紧凑工具界面；桌面信道表、参数抽屉与手机断点。

**网页读取与小范围增量写入已在实机通过。** v0.4.0-beta.3 修复连续会话的 `55` 启动输出错误；信道名称、扫描添加和开机文字三块写入均获确认，全区回读一致，测试值已恢复。编辑后直接点击“写入修改”，只写变更块，备份与校验自动完成。整表、大范围参数及物理断电持久化验证仍待完成。不支持固件升级、校准或独立信令码组编辑；“加电按键开机”映射仍有疑点，保留原值。具体边界见[验证记录](docs/VALIDATION.md)。

## 使用

1. 使用电脑 Chrome / Edge 打开 HTTPS 工作台，接好已开机的 D500 和写频线，关闭其他占用串口的软件、释放云电脑 USB。
2. 在“电台读写”中选择写频线并读取。原始配置先保存本机备份，再选择替换、合并或仅载入配置。
3. 在信道表及电台设置中编辑。Excel 导入可按编号合并，表格未提供的字段沿用现有同编号信道。
4. 进入“电台读写”，选择同步范围，检查修改并主动确认写入。写前重新读取，写后完整回读；异常停止后重新读取检查。
5. 也可导出 DAT 供原厂软件使用，或下载包含模板、设置、分组与备注的完整方案。

导出 DAT 需要同机读取或原厂导出文件作为基线。空白项目可先导入表格、保存完整方案，稍后读取本机配置再合并。不会拿另一型号的默认配置覆盖电台。

## 格式与兼容

- 原生编号 0–199，显示为 000–199；既有 `#` 表头中 200 映射到 000。
- 信道频率使用 MHz，精度 10 Hz；发射频率留空表示接收专用。
- 模拟哑音如 `88.5`，数字哑音如 `D023N` / `D023I`；未知原始值保留。
- 新增或更名使用已验证的官方 V1 保存路径的 8 个 GBK 字节限制，常用汉字 4 个。原 DAT 的长名称未编辑时保留；16 字节记录不代表屏幕显示能力。
- VFO 频点是逐位十进制数组，频差使用 0.001 MHz；与信道 BCD 编码不同。
- 分组和备注只保存在完整方案中。
- 旧项目新增字段从原 DAT 继承，不用默认值覆盖用户配置。

基础编解码衍生自 [Liuli-Lumine/K1toD500](https://github.com/Liuli-Lumine/K1toD500)，上游修订 `e65cbb309986f0f37babaae7fac77f9fd21b5ab1`。原厂二进制、私人 DAT / 表格、串口原始记录和服务器凭据均不进入 Git 或部署包。

## 开发与部署

Node.js 22.12+：

```sh
npm ci
npm test
npm run build
npm run dev
```

React、TypeScript、Vite；SheetJS CE 0.20.3 固定在 `vendor/`。公开测试使用合成数据，本地存在被忽略的私有夹具时补充文件回归。

```sh
# 提交之后发布；使用本机现有 SSH 配置。
bash scripts/deploy.sh
```

现有 VPS 静态容器经 Nginx Proxy Manager 提供 HTTPS。发布生成与提交对应的 `source.zip`、`LICENSE.txt`、`version.json`，采用可回退版本目录。详见[部署说明](docs/DEPLOYMENT.md)。
