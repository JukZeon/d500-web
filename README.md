# D500 Workbench

**BA7KTC / JukZeon 的 D500 网页信道工作台。**

站点：https://d500.example.com

为旧版、没有航空 AM 接收的即时通 D500 设计。文件在浏览器本地解析和编辑，不上传 DAT、工作表或方案内容。

## 功能

- 000–199 原生信道编号，可视化表格编辑、参数面板与频率分布图。
- 名称、接收/发射频率、CTCSS/DCS、功率、带宽和繁忙禁发编辑。
- 搜索、频段筛选、分组、备注、多选批量编辑、复制、删除和撤销/重做。
- 导入旧版原厂 DAT，修改后导出；保留非信道配置、未编辑标志位与原始 GBK 名称编码。
- 无修改导出与原文件逐字节一致；有修改时仅重写明确编辑的字段。
- XLSX、CSV、TSV 导入；XLSX、CSV 和空白模板导出；支持 K5Web 常见工作表。
- 浏览器自动保存、完整 `.d500.json` 方案备份与恢复。
- 响应式桌面/手机布局；所有字体、脚本和样式随站点托管。

## 使用

1. 用 **D500 V1 原厂写频软件**读取机器，并保存原始 DAT 备份。
2. 在网页中导入 DAT，确认预览后替换列表；也可只载入模板。
3. 直接编辑信道表，或点选行在右侧编辑全部参数。支持粘贴表格。
4. Excel 导入可替换列表或按原生编号合并，同编号以导入内容为准。表格未提供的带宽等字段沿用现有同编号信道。
5. 导出 DAT，在原厂软件中打开、核对后写入电台。

新建空白方案可直接导出表格或方案备份；导出 DAT 需要先载入本机原始 DAT 模板。项目没有使用 K1toD500 的 V2 默认配置替代 V1 设置。

### 格式约定

- D500 原生编号：0–199，界面显示为 000–199。
- K5Web `#` 编号：1–199 保持不变，200 映射到 D500 的 000。
- 频率单位 MHz，最多 5 位小数（10 Hz）。发射频率留空使用 DAT 的全 FF 编码表示接收专用；新增此类配置仍需原厂软件核对。
- 亚音留空表示关闭；模拟亚音示例 `88.5`；数字亚音示例 `D023N` / `D023I`。
- 名称最多 16 个 GBK 字节（一般为 8 个汉字）；不静默截断或用问号替换。
- 出厂文件中的非标准亚音用 `RAW:<原值>` 保留。
- 分组、备注仅保存在网页方案和表格中，不写入 DAT。
- 导出表格不添加 BA7KTC 个人署名。

## 兼容与验证边界

DAT 布局移植自 [Liuli-Lumine/K1toD500](https://github.com/Liuli-Lumine/K1toD500)，修订 `e65cbb309986f0f37babaae7fac77f9fd21b5ab1`。工作流程参考 [K5Web](https://github.com/silenty4ng/k5web)。

已用 BA7KTC 提供的旧版 `KTC.dat`（113 条有效信道）与 `出厂值参考.dat`（8 条有效信道）验证 1025 行格式、GBK 解析、无修改逐字节往返和单字段修改。个人原始文件留在被忽略的本地 `.deploy/private-fixtures/` 中，不进入 Git、源码下载或部署包。

当前版本负责文件管理，**没有实现电台 USB 读写协议或固件升级**。文件往返验证不等于已经实机写入验证。用原厂软件读取、保存和核对，保留原始备份。

## 开发

Node.js 22.12+：

```sh
npm ci
npm test
npm run build
npm run dev
```

React + TypeScript + Vite；SheetJS CE 0.20.3 使用官方分发包固定在 `vendor/`，不依赖过期的 npm 同名包版本。`package-lock.json` 固定依赖。

公开测试涵盖 DAT 布局验证、BCD、亚音、GBK、未知字节保留、复制、删除、模板要求、XLSX 往返、K5 编号映射和项目校验。本地存在私有夹具时另运行对应回归测试。

## 部署与回退

详见 [部署说明](docs/DEPLOYMENT.md)。站点使用独立的只读静态容器，通过已有 Docker `proxy` 网络接入 Nginx Proxy Manager，不直接暴露容器端口。

```sh
# 先完成提交，再部署；使用本机已有 SSH 配置。
bash scripts/deploy.sh
```

每次发布生成对应版本的 `source.zip`、`LICENSE.txt` 和 `version.json`。源码下载排除本地研究二进制和个人测试文件。
