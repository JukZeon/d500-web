# D500 V1 DAT 格式研究

2026-10-27，BA7KTC / JukZeon，Workbench v0.2.0。

## 范围与证据

研究对象是[官网 D500 VIP V1 写频软件](https://www.zastone.com.cn/download/showdownload.php?id=197)中的 `D500_vip_CPS.exe`，文件版本 1.0.0.0，PE32 x86、VB6 原生编译，大小 1,564,672 字节。SHA-256：

```text
c2d7e2d42a78d949b03d7557b0785139a856485d20c0cb12e9ae43979a3c3559
```

[官网 V2 页面](https://www.zastone.com.cn/download/showdownload.php?id=290)明确说 V2 仅适用于带航空接收的机器，不能用于 V1。下述映射针对上面固定版本，不外推为全部硬件或软件版本。

方法：提取安装 CAB，读取 PE 导入、VB6 对象/控件/事件表、BSTR 选项文本，追踪控件 Click 到 DAT 数组赋值的地址与掩码。未修改原厂软件，未提取或分发其源码。原厂 EXE、完整反汇编及个人 DAT 不进入仓库或部署包。

`scripts/inspect-cps.py` 可重现 29 个对象的控件/事件映射；参数表的原生处理函数地址见 `src/lib/settings.ts`。信道核心处理函数为 `frm_chann.Combo_edit_Click`，VA `0x47a8f0`。

## 文件结构

每个非空文本行含 19 个十进制整数，共 1025 行：

```text
floor(row / 16)  row % 16  row  byte0 ... byte15
```

| 行号（从 0 开始） | 内容 | 当前处理 |
| --- | --- | --- |
| 0–199 | 200 个信道，每信道 16 字节 | 已确认字段可编辑 |
| 200–223 | 额外记录/保留 | 保留 |
| 224–239 | 菜单和部分信令 | 白名单字段可编辑，其余保留 |
| 240–247 | A/B/C/D 频率区，每区两行 | 每区 7 项已确认参数可编辑 |
| 248–255 | 其他配置 | 保留 |
| 256–455 | 信道名称，每条分配 16 字节 | 新增/更名执行 V1 8 字节兼容限制 |
| 456–1024 | 其他表、信令、FM、校准或保留数据 | 保留，不猜测含义 |

没有变更时返回原文件文本，包括 BOM、空白和换行；有变更时只更新对应字段的数据值，文本空白统一。名称未改、复制或移动时保留原编码字节。

## 信道记录

以下字节偏移从 0 开始；每行前三个地址整数不计入偏移。

| 偏移 | 含义 | 编码/掩码 | 原生处理位置 |
| --- | --- | --- | --- |
| 0–3 | 接收频率 | MHz × 100000，十进制 BCD，小端 | 基础编解码 |
| 4–7 | 发射频率 | 同上；全 FF 为仅接收 | 基础编解码 |
| 8–9 | 接收哑音 | uint16 LE | 基础编解码 |
| 10–11 | 发射哑音 | uint16 LE | 基础编解码 |
| 12 低 4 位 | 信令码组 | 0–14 显示为 1–15 | `0x47bbfb` |
| 13 低 4 位 | 可选信令 | 0 关、1 DTMF、2 2TONE、3 5TONE | `0x47bca3` |
| 13 高 4 位 | 静音方式 | 0 QT、1 AND、2 OR | `0x47bd4b` |
| 14 低 2 位 | 发射功率 | 0 高、1 低；其他值保留 | `0x47b871` |
| 14 bit 4 | 扰频 | 0 关、1 开 | `0x47be16` |
| 15 低 2 位 | PTT-ID | 0 OFF、1 BOT、2 EOT、3 BOTH | `0x47b9d0` |
| 15 bit 2 | 扫描添加 | 0 不参加、1 参加 | `0x47bb7c` |
| 15 bit 3 | 繁忙禁发 | 0 关、1 开 | `0x47ba78` |
| 15 bit 6 | 带宽 | 0 宽、1 窄 | `0x47b951` |

仅替换字段掩码内的位。导入的陌生枚举值保留；不因为它未在预设中而改写。未触及的位，包括扰频开关以外的高位，继续保留。

### 哑音

- 0：关闭。
- 1–105：标准 DCS 码表的正码；106–210：同一顺序的反码。
- 模拟 CTCSS：Hz × 10，例如 88.5 Hz → 885。
- 不能解释的数值（例如 65535）显示为原始值并保留，不擅自当成关闭。
- 网页区分 CTCSS/DCS 类型，DCS 编码与 N/I 极性独立选择。数字哑音不是 DMR 数字通信模式。

## 名称长度的实际验证

不能用“DAT 分配了 16 字节”推出“电台支持 8 个汉字”。此结论是初版沿用上游 V2 工具说明产生的错误，v0.2.0 已撤回。

这份官方 V1 的信道名称保存路径中：

1. `0x48bd1d` 附近先检查文字长度，提示字符串为“信道名称的字符个数最大为 8 ！”。
2. `0x48c2b3` 附近将字符串转换为 ANSI 字节数组（按中文 GBK 环境验证）。
3. `0x48c34c`–`0x48c38b`：若字节数组上界 ≥ 8，则把上界改成 7。
4. `0x48c391`–`0x48c4ac`：仅复制第 0–7 字节。
5. 后续逻辑检测双字节序列边界；若截断处落在半个汉字上，丢弃该不完整字节。

在 Unicorn x86 指令模拟器中执行上述原厂字节码；初始化其输入数组、清空后的名称记录和最小 VB6 整数/循环帮助函数，结果如下：

| 输入 | GBK 字节数 | 该保存路径写入 |
| --- | ---: | --- |
| 一二三四 | 8 | 一二三四 |
| 一二三四五 | 10 | 一二三四 |
| 一二三四五六七八 | 16 | 一二三四 |
| ABCDEFGH | 8 | ABCDEFGH |
| ABCDEFGHIJ | 10 | ABCDEFGH |
| A一二三四 | 9 | A一二三 |
| 测试名称五 | 10 | 测试名称 |

这证实了**固定版本软件的名称复制路径为 8 字节，常用汉字相当于 4 个**，不能确认“5 个”或“8 个汉字”。运行库帮助函数由测试替身实现，此验证没有运行完整 Windows GUI，也没有写入电台或验证 LCD 显示。当前本机的 Windows 虚拟机磁盘不在线，因此不能把这个结果说成原厂界面实测。

复现命令（依赖仅用于研究，不参与网页运行）：

```sh
python3 -m venv /tmp/d500-cps-check
/tmp/d500-cps-check/bin/pip install pefile capstone unicorn
/tmp/d500-cps-check/bin/python scripts/inspect-cps.py /path/to/D500_vip_CPS.exe -o /tmp/cps-map.json
/tmp/d500-cps-check/bin/python scripts/verify-cps-names.py /path/to/D500_vip_CPS.exe -o /tmp/name-results.json
```

网页新增或更名使用 8 字节限制，并明确报错，不模仿原厂软件的静默截断。原 DAT 中已经存在的长名称，只要未编辑其名称，允许原样导出、复制或移动。原始结果见 [cps-name-verification.json](cps-name-verification.json)。

## 整机菜单与 VFO

菜单索引 `i` 对应行 `224 + floor(i / 16)`、字节 `i % 16`，保存 ComboBox 的零基 ListIndex。索引初始化函数 `0x526260`；例如 SQL 索引 2（全局变量 `0x57c52c`）由 `0x4a4e80` 写回行 224 字节 2。

目前编辑白名单共 38 项：TDR、SQL、TOT、自动锁键、语言、提示音、DTMF 侧音与增益、繁忙禁发、扫描添加/恢复、PTT-ID/延迟、报警类型/信道、有效信令提示音、A/B 显示、VOX/延迟、8 项颜色、ANI 长度、中继激活音、APO、TDR 返回、STE/RP-STE/RPT-DL、扬声器/麦克风/面板。具体索引、选项顺序和原生地址在 `MENU_SETTINGS` 中。

频率区 A/B/C/D 的参数行为第 241/243/245/247 行；相邻前一行含十进制数字数组形式的频点等数据，不能套用信道 BCD。

| 参数行字节 | 参数 | A/C 控件地址 | B/D 控件地址 |
| --- | --- | --- | --- |
| 4 | 信令码组 | `0x4a2030` | `0x4a2260` |
| 5 | 静音方式 | `0x4a4a20` | `0x4a4c50` |
| 6 | 可选信令 | `0x49d940` | `0x49db70` |
| 8 | 带宽 | `0x4aa4a0` | `0x4aa6d0` |
| 9 | 高/低功率 | `0x4a9410` | `0x4a95f0` |
| 10 | 频差方向 | `0x4a3ee0` | `0x4a4110` |
| 11 | 步进 | `0x4a6410` | `0x4a6640` |

VFO 频点、频差数值及哑音暂只读/保留；信令码组具体内容、密码、校准、FM 广播等不开放猜测性编辑。整机数值延迟选项若没有独立单位证据，沿用软件的档位编号，不附加猜测单位。

## 既有表格兼容

BA7KTC 原有表格把接收/发送亚音分为类型、Hz 和数字码；新导出延续这个结构。`D252N` 一类显式极性后缀优先于 `DCSH` 等旧类型名。旧表缺少的带宽、扫描和信令参数沿用现有同编号信道。

旧表的“信令码”“DTMF 解码”“扫描列表”不能直接视为本机同义字段，不自动套用；新的 D500 表使用明确的“信令码组”等标题。DMR 选项不转成 D500 V1 功能。表格不附加个人署名。
